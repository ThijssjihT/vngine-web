Code walkthrough

This walkthrough follows the engine in the order it runs: from launching the app, through the first scene, to saving a game. Open the code alongside and read along.

It describes engine commit 2537d6d (3 November 2026). Engine code lives under qml/engine/; the game itself lives under qml/game/ and is covered in Game authoring.
