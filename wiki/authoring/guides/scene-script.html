Scene script commands

A scene is a JSON file holding a flat list of commands. The engine runs them one after another and only stops where the player has to do something — a line of dialogue to tap through, or a choice to make.

Path: qml/game/script/<scene_id>.json

Everything on this page can be written by hand, and everything on this page can also be built in the scene script generator, which draws the branching as a map and warns about the mistakes that are easy to make once a scene has more than one route through it.

{
    "id": "scene_0001",
    "commands": [
        { "cmd": "bg",  "image": "bg/centre_exterior_evening.png" },
        { "cmd": "say", "speaker": null, "text": "You are at your local community centre." },
        { "cmd": "jump", "scene": "scene_0002" }
    ]
}
Authoring rule — a scene must end with a jump. Running off the end of the command list is an authoring error; the engine warns and pops back out of the game screen.

Implemented commands

CommandKeysWhat it does
sayspeaker, text Shows a line in the textbox with the typewriter effect and waits for a tap. "speaker": null means narration.
bgimage Sets the background, relative to assets/. Continues immediately.
spriteid, image, position Shows or replaces a sprite. Re-using an id swaps that sprite's image and position.
sprite_removeidRemoves that sprite.
setvar, op, value or from Changes a variable. See Variables and conditions.
labellabel A marker to jump to. Does nothing on its own. Labels are indexed per scene, so a label is only reachable inside its own scene.
jumplabel or scene Continues somewhere else.
jump_ifcondition + label/scene Jumps only when the condition is true, otherwise falls through to the next command.
choiceoptions Shows a menu and waits. See below.
stylecategory, style Switches the active style for textbox, choice or hud. If the style cannot be loaded the current one is kept and a warning is logged.

An unknown command is logged and skipped, so a typo will not stall the game — but it will not do what you meant either. Watch the console output while testing.

Dialogue

{ "cmd": "say", "speaker": null,    "text": "The noticeboard is covered in paper." }
{ "cmd": "say", "speaker": "Liisa", "text": "Like this, %player_title%?" }

Every displayed string passes through variable interpolation: %name% is replaced by the variable of that name, or by a setting of that name. An unknown name is left as-is and logged.

Sprites

{ "cmd": "sprite", "id": "liisa", "image": "sprites/liisa_1.png", "position": "left" }
{ "cmd": "sprite", "id": "liisa", "image": "sprites/liisa_2.png", "position": "60%,0" }
{ "cmd": "sprite_remove", "id": "liisa" }

position accepts left, right, anything else centres the sprite, or a percentage pair like "60%,0" to place it by hand. The percentage is the horizontal centre of the sprite.

Choices

{
    "cmd": "choice",
    "options": [
        {
            "text": "Don't panic",
            "condition": { "var": "panic", "op": "<", "value": 3 },
            "label": "dont_panic"
        },
        {
            "text": "Panic",
            "condition": null,
            "effects": [ { "var": "panic", "op": "sub", "value": 1 } ],
            "label": "label_panic"
        },
        {
            "text": "Panic hard",
            "effects": [ { "var": "panic", "op": "sub", "value": 1 } ]
        }
    ]
}
KeyMeaning
textThe option label. Interpolated like dialogue.
conditionOption is hidden unless this is true. null or absent means always visible.
effectsList of set-style changes applied when the option is picked.
labelWhere to continue. Without it, the script simply carries on after the choice.

If every option is hidden, the engine warns and skips the choice rather than trapping the player — so make sure at least one option has no condition.

Styles mid-scene

{ "cmd": "style", "category": "textbox", "style": "colorful_textbox" }

Build the style file with the textbox style generator.
