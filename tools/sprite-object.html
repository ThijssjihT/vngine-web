Sprite object editor

Builds a sprite object: a .json file that stacks several images in layers and animates them, such as a character who blinks. Save it under qml/game/assets/sprites/ and name it in a scene's sprite command instead of a .png. Load your sprites folder to see the real images in the preview. Nothing is uploaded.

Pick your game's assets/sprites folder (picking assets or the whole game folder works too). Image paths are always relative to assets/sprites/, wherever the sprite object itself is saved. Images stay in your browser and nothing about them is written into the file.

Layers

A layer is a depth. Every image sits on one layer, and a higher z is drawn on top. The order of this list does not matter.

Assets

One row per image. The order matters twice: the first asset sets the sprite's width, and assets on layers with the same z are drawn in this order, later on top. Every asset is hidden until an animation step shows it.

Animations

Each animation shows exactly one of its assets at a time. All of them start together and run independently. A loop repeats; a once runs through and then holds its last step for good. A part that never changes, such as a body, is a one-step once. Durations are in milliseconds; randomize adds or subtracts up to that much, drawn fresh each time the step comes round.
