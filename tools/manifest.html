Manifest (game.json)

One file at the root of your game folder. It tells the engine what your game is called, where the story starts, what the settings page contains, and which variables exist before the first command runs.

Path: qml/game/game.json

Core keys

KeyTypeMeaning
titlestringGame title, shown on the title screen.
versionstringYour game's version, independent of the engine version.
taglinestringOne-line description shown under the title.
entry_scenestringScene id the game starts from, e.g. scene_0001. The file must exist as script/<id>.json.
default_languagestringLanguage code used when nothing else is chosen.
save_display_variablestringName of a variable whose value is used as the label on save slots. If it is not declared under variables, the engine creates it with the value "empty".
default_stylesobjectStyle id per category applied at the start, e.g. { "textbox": "boring_textbox" }. See Styles.
creditsobjectNamed blocks of credit lines. Each value is an array of strings, shown as a block.

Variables

Every variable your script uses should be declared here, with a starting value. The engine reads the default of each entry when a new game starts.

"variables": {
    "panic":         { "type": "int",    "default": 1 },
    "chapter_title": { "type": "string", "default": "Prologue" }
}

See Variables and conditions for how to read and change them.

Settings

The settings page is built from the manifest — you describe the controls, the engine renders them and stores the values. Settings can be read from the script exactly like variables.

Audio channels

The engine has five fixed audio channels. They always exist, whether or not the manifest mentions them, and each visible one gets a volume slider on the Settings screen. You cannot add channels of your own; audio_channels only adjusts the five that are there.

ChannelUsed byLabelDefaultShown
musicaudio_bgMusic80yes
game_fxaudio_fxSound effects80yes
looping_fxaudio_loopAmbience80yes
voice— (planned)Voice100no
text_fx— (planned)Text sounds40no

Each entry under audio_channels overrides any of three keys for one channel; anything you leave out keeps the engine value.

KeyTypeMeaning
labelstringText next to the slider.
defaultnumber, 0–100Starting volume in percent, until the player moves the slider.
hiddenboolLeave the slider off the Settings screen.
"audio_channels": {
    "music":      { "label": "Soundtrack", "default": 60 },
    "looping_fx": { "hidden": true }
}

Hiding a channel only removes its slider. The channel still plays, at its default volume, so hide the channels your game does not use rather than the ones it does. Setting "hidden": false on voice or text_fx shows a slider, but nothing plays on those channels yet. A key that is not one of the five channels is ignored, with a warning in the log.

Languages

"languages": {
    "text":  { "label": "Language", "options": ["English", "Nederlands"], "default": "English" },
    "voice": { "label": "Voice",    "options": ["English", "Japanese"],   "default": "English" }
}

Toggles, dropdowns, text fields and sliders

"toggles": {
    "arachnofobia": { "label": "Arachnofobia mode", "default": false }
},
"dropdowns": {
    "difficulty": { "label": "Difficulty", "options": ["easy", "normal", "hard"], "default": "normal" }
},
"textfields": {
    "player_title": { "label": "What do others call you by?", "default": "Mister" }
},
"sliders": {
    "starting_wealth": { "label": "Starting wealth", "min": 10, "max": 100, "stepsize": 1, "default": 20 }
}
Design limit — up to four of each: four toggles, four dropdowns, four text fields and four sliders. This is a deliberate limit on how much a settings page should hold, not something the engine enforces today.

A text field value can be dropped straight into dialogue with %player_title%, and any setting can be tested in a condition with { "setting": "difficulty", "op": "==", "value": "hard" }.
