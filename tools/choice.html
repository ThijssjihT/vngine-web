Copy Onto

No textbox style loaded. The preview uses the engine defaults for the dialogue box behind the choices.

Only the values the textbox file actually sets are copied. A file exported with only changed values ticked sets just a few keys, and everything it leaves out stays as your parent style has it — the copy never writes an engine default over an inherited value.

This is a one-time copy into the form below, not a live link — the engine has no cross-category inheritance, so the values are written into your choice file as ordinary overrides and will not follow later edits to the textbox style. Copying the background onto both the grid and the options stacks the two alphas, so the options come out darker than the textbox. Text colour is not copied: the textbox schema has no text colour yet.

Grid — layout

Fraction of the width the left and right margins leave. The grid's height comes from its contents, so there is nothing to set for it.

Grid — margins (outside the frame)

Margins inset the region the grid is centred in. Equal left and right margins therefore look the same as none; uneven ones shift the grid.

Grid — padding (inside the frame)
Grid — background and border

A frame background only shows where the options do not cover it — the padding, the spacing gaps, and any rounded corners.

Option — size and padding

An option is as wide as the grid and its columns allow, and as tall as its text needs. This only stops a one-word option from collapsing to a sliver.

Option — background and border

Option — text

Written as null when it follows the ambience, which is what the engine default does. A fixed colour is the right choice as soon as the option background is a colour of your own, since the ambience does not know about it.
